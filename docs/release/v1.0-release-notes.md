# GRC Skill Agent v1.0 发布说明（2026-11-02）

## 交付范围

- **52 KU**：EU AI Act 32 + 中国生成式 AI 20（暂行办法 13 + 标识办法 7）。
- **8 页**：concept/entity/overview/source/topic，含 EU/CN 双域。
- **20 金标 + 5 负例**；eval 20/20 mode、negative 5/5、host 15/15。
- **MCP stdio**：search_kus/get_ku/get_page/ask/validate_answer/freshness + resolve_clarify。
- **术语标准 v1.1**；设计基线 v1.0（check_design 127/0）。
- **0 errors / 0 warnings**；impact CI 0。

## 发布包不含

- `kb/snapshots/`（Tier A 全文快照，仅本地/私有核验；不随包、不公开）；
- `docs/research/sources/`（官方全文原始件）；
- `var/`（运行时答案/密钥）；
- 评审通讯目录与内部评审包。

发布包只含 KU、Scope Registry、verification 元数据（含 `fulltext_sha256` 字段）、页面、代码、spec、术语标准、eval 与演示脚本。

## 使用

```bash
./bin/grc validate
./bin/grc eval
./bin/grc ask "欧盟 AI Act 下高风险系统有哪些义务？"
./bin/grc-mcp
```

> 不带快照时，`validate` 的 CK-03 全文子串校验不可执行；这是发布边界，不是缺陷。核验请在持有快照的本地/私有 CI 执行。
