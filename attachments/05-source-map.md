## 2. EU AI Act：与本项目相关的**关键时间线**（已按合并版核实）

来源：EC AI Act Service Desk, Article 113（访问 2026-10-31），其正文由 EUR-Lex consolidated 27 July 2026 生成：

| 事项 | 日期 |
|---|---|
| 条例生效 | 公布后第 20 日（2024-08-01） |
| 一般适用 | **2026-08-02** |
| 第 I、II 章（除 Art.5(1) 首段 (ba)(bb)、Art.5(1a)(1b)） | 2025-02-02 |
| Art.5(1) (ba)(bb)、Art.5(1a)(1b)（Digital Omnibus 新增/修订） | **2026-12-02** |
| 第 III 章第 4 节、第 V、VII、XII 章、Art.78（除 Art.101） | 2025-08-02 |
| 第 III 章第 1/2/3 节（高风险，除 Art.6(5)）：Annex III 类 | **2027-12-02** |
| 同上：Annex I 类 | **2028-08-02** |
| Art.102–110 | 2026-07-27 |

**结论（对 KU 的直接影响）**：
- 高风险义务（Art.8–15 / 16 / 26 / 27 / 43）的适用日**不是** 2026-08-02，而是 **2027-12-02（Annex III）/ 2028-08-02（Annex I）**；
- 若使用原始 2024 版 Art.113，会写成 2026-08-02 —— 这正好是 **"改 1 条 KU 触发传导"的最佳演示素材**（原始版 vs 合并版）；
- 本项目的 `as_of` 必须写 2026-10-31，`source_url` 用 consolidated CELEX。

**条款清单（已核实存在，Article Explorer）**：Art.2 范围；Art.5 禁止实践（含新增 (ba)(bb)）；Art.6 + Annex III 分类；Art.8–15 要求；Art.16 提供者义务；Art.26 部署者义务；Art.27 FRIA；Art.43 合格评定；Art.50 透明度；Art.113 时间线。

## 3. CN《生成式人工智能服务管理暂行办法》（24 条，2023-08-15 施行）

**关键范围条款（Art.2，逐字）**：

> 利用生成式人工智能技术向中华人民共和国境内公众提供生成文本、图片、音频、视频等内容的服务（以下称生成式人工智能服务），适用本办法。
> …行业组织、企业、教育和科研机构、公共文化机构、有关专业机构等研发、应用生成式人工智能技术，**未向境内公众提供生成式人工智能服务的，不适用本办法的规定**。

## 6. 抓取与核验可行性（实测）

| 来源 | 脚本抓取 | 备注 |
|---|---|---|
| gov.cn（暂行办法） | ✅ 200，39 KB | 稳定 |
| cac.gov.cn（标识办法） | ✅ 200，23 KB | 稳定 |
| EUR-Lex（consolidated HTML） | ❌ 返回 0 字节（curl，带浏览器 UA 亦然） | 反爬/网关限制；**online 自动核验不可依赖** |
| EC AI Act Service Desk | ✅ 可读（条文页） | 可作人工核验的官方入口 |

**结论（修改设计 C1）**：
- `verification` 由三态改为**四态**：`online`（脚本抓取成功）｜`manual`（人工打开官方页面核对并留痕）｜`offline`（仅 KU↔快照自洽）｜`expired`。
- MVP 默认 `manual`；`online` 仅对可稳定抓取的来源启用；EUR-Lex 类来源的 `online` 作为 v0.2 目标（官方 API 或人工代理）。
- 每个 KU 的 `verification` 与 `verified_at` 在答案中显示。
